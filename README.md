## 📌 Enquadramento
Desenvolvimento da prova de conceito para integração das novas entidades `sponsors` e `experts` na aplicação Animalec.

Nesta fase foram introduzidas:
- Reatividade com **Vue.js 3** para navegação SPA no Back-Office;
- Simulação dinâmica das rotas `/admin/sponsors` e `/admin/experts`;
- Barra superior de alternância entre vista **Browser (Desktop)** e vista **Mobile**;
- Filtros por categoria e campos de pesquisa em tempo real.
